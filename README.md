## How I use this library

Each subfolder is a self-contained Claude Skill. To use one in Claude.ai:

1. Download this repo as a ZIP (green `<> Code` button → Download ZIP) or download just the skill folder you want.
2. Extract it on my computer.
3. Upload the specific skill folder to Claude.ai's Skills section.
4. Use only one skill at a time — remove the previous one before uploading a new one.

## Editing skills

I edit directly on GitHub using the in-browser editor (press `.` while viewing any file to open the full editor). No local install needed.
